# ETTP

## Entity Trust Transfer Protocol

ETTP is an open protocol for representing and evaluating trust between
autonomous entities.

The protocol is designed for systems including:

- AI agents
- AI models
- software services
- robots
- drones
- autonomous vehicles
- IoT devices
- sensors
- actuators
- future autonomous machines

## Project Status

ETTP is currently under active development.

Current milestone:

**Sprint 0 — Architecture Foundation**

Sprint 0 establishes the repository, development tooling, CI,
schema-validation infrastructure, protocol versioning, and contribution
framework.

No policy features are implemented yet.

## Architecture Principle

ETTP is a protocol, not a centralized SaaS product.

The protocol must remain language-independent.

JSON Schema defines the protocol wire format.

The Python implementation is the first reference implementation.
