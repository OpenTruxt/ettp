# Code of Conduct

## Our Commitment

We are committed to providing a professional, respectful, inclusive,
and technically constructive environment for everyone participating
in the ETTP project.

## Expected Behavior

Participants should:

- communicate respectfully
- focus criticism on ideas and implementations
- welcome technical disagreement
- provide constructive feedback
- respect different levels of experience
- prioritize the security and interoperability of the project

## Unacceptable Behavior

Harassment, discrimination, intimidation, threats, personal attacks,
and deliberately disruptive behavior are not acceptable.

## Enforcement

Project maintainers may take appropriate action when this code of
conduct is violated.
