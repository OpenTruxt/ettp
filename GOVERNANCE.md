# ETTP Governance

ETTP is developed as an open protocol.

Governance must protect:

- protocol interoperability
- security
- technical quality
- backward compatibility
- transparent evolution
- implementation neutrality

Protocol changes should be discussed openly and documented.

Implementation details must not unnecessarily become protocol requirements.

Major protocol changes should include compatibility and migration
considerations.

The governance model will evolve as the protocol and contributor
community mature.
